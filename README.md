# FallCrate
A aplicação FallCrate foi desenvolvida para a disciplina de Sistemas Operacionais da Universidade Tecnológica do Paraná, ministrada pelo Prof. Dr. Rodrigo Hübner.

## Resumo da aplicação:
A aplicação funciona como um "guardião de arquivos", ou seja, utiliza um diretório especificado pelo usuário para verificar se os arquivos (também das subpastas) dentro dele estão íntegros. Essa verificação da integridade dos arquivos vai ser feita utilizando o ~~Md5 ou Md6~~.

## Funcionalidades:
As funcionalidades pedidas pelo professor são as seguintes:
- **Cadastro da referência inicial**: percorrer os arquivos de um diretório e armazenar
seus nomes, caminhos relativos e hashes criptográficos.
- **Verificação de integridade:** comparar os arquivos atuais com a referência
previamente armazenada.
- **Identificação de alterações:** detectar arquivos modificados, arquivos novos e
arquivos removidos.
- **Geração de relatórios:** apresentar os resultados da verificação de maneira
organizada, identificando os arquivos afetados.
- **Registro de eventos:** manter um log das verificações realizadas, incluindo data,
horário e resultado da execução.
- **Tratamento de erros:** identificar situações como diretórios inexistentes, arquivos
inacessíveis ou falhas na execução.
